# data/

Выгрузки из учетных систем. Содержимое папки игнорируется git целиком, в репозиторий
попадает только этот файл и `.gitkeep`.

## Слои

```
data/
  raw/    сырые выгрузки как пришли: транзакции, договоры, уведомление о СТП (docx)
  anon/   то же после анонимизации: номера договоров заменены на HMAC, регион сокращен до отделения
```

Папки `raw/` и `anon/` создаются вручную или при первом запуске загрузчика. Пустые папки
git не хранит, поэтому в репозитории их нет.

Выгрузка, загруженная через страницу, лежит в скрытой `raw/.upload-<id>/` только до конца
обработки и удаляется, чем бы та ни кончилась. Обработка пишет во временную `.anon-<id>/`
рядом с `anon/` и заменяет данные только после проверки.

## Правило работы

`raw/` не выходит за пределы машины. Все, что уезжает наружу — сессия Claude Code в облаке,
push в GitHub, запуск CI — работает либо с `anon/`, либо с синтетическими фикстурами из
`tests/fixtures/`.

Таблица обратного соответствия анонимизации (`*.mapping.json`) и ключ HMAC из `.env`
в корне данных лежат локально и в git не попадают.

## Что нужно на входе

| Файл | Содержимое |
|---|---|
| транзакции | договор, сегмент, регион, продукт, литры, выручка после скидки, сбор, месяц |
| договоры | номер, сегмент, дата подключения |
| уведомление о СТП (docx) | шкала СТП по объему выборки, сетевая и трассовая |
| экономика | цена, себестоимость, OPEX, маржа по месяцам и регионам |
| таблица отделений | `anon/branch_regions.csv`: отделение и регион прогноза маржи, к которому оно относится |

Таблицу отделений ведут руками или заполняют формой на странице: в выгрузке связи между
отделениями транзакций и регионами прогноза нет, и `prepare` таблицу не создает и не трогает.
Форма предлагает только регионы из прогноза маржи загруженной выгрузки. Колонки `отделение,регион`,
одна строка на отделение. Отделение из транзакций, которого нет в таблице, останавливает
расчет; регион прогноза без отделения в расчет не попадает.

Параметры конкретной акции задаются не здесь, а конфигом в `configs/`. Настоящие конфиги
в git не попадают, в репозитории лежат условные примеры.
