# Установка на Mac

После установки на этом Mac работает страница: в нее перетаскивают выгрузку
и уведомление о СТП, задают параметры акции и скачивают готовую книгу. Файлы
остаются на этом компьютере, в сеть ничего не уходит.

Нужно один раз: поставить Docker Desktop и выполнить три команды. Дальше
страница всегда под рукой, в том числе после перезагрузки.

## 1. Docker Desktop

1. Скачать с https://docs.docker.com/desktop/setup/install/mac-install/
   и установить: перетащить в «Программы». На странице два варианта, Apple
   silicon и Intel; какой чип, видно слева вверху: яблоко → «Об этом Mac».
2. Запустить Docker Desktop. При первом запуске он попросит принять
   соглашение и, возможно, пароль от Mac.
3. Дождаться, когда в строке меню появится значок кита и перестанет двигаться.

## 2. Три команды

Открыть Терминал: ⌘ Пробел, набрать «Терминал», Enter. Вставлять по одной
команде, после каждой Enter, и дождаться приглашения для следующей.

```bash
mkdir -p ~/mk-forge && cd ~/mk-forge
```

```bash
curl -fsSLo compose.yaml https://raw.githubusercontent.com/blashkin/mk-forge/main/compose.yaml
```

```bash
docker compose up -d
```

Третья команда в первый раз скачивает около 250 МБ. Когда она закончится,
страница готова.

## 3. Страница

Открыть в браузере http://127.0.0.1:8765. Версия видна в шапке. Дальше
страница ведет сама, порядок такой:

1. В блок «Данные» перетащить выгрузку `.xlsx` и уведомление о СТП `.docx`,
   можно вместе. Сам файл не меняется, страница берет копию. Она покажет шаги
   обработки и итог: сколько договоров, транзакций и отделений загружено.
2. В «Таблице отделений» для каждого отделения выбрать регион прогноза маржи
   и нажать «Сохранить таблицу отделений». Пары по названию не подбираются:
   если не уверены, уточнить до сохранения. После сохранения появится форма
   акции.
3. Проверить параметры в форме и нажать «Собрать книгу». Дождаться строки
   «книга собрана и сошлась с расчетом».
4. В «Готовых книгах» нажать «скачать книгу».

Закрыть вкладку можно в любой момент: данные, параметры и книги остаются.
После перезагрузки Mac ничего вводить не нужно: как только запустится Docker
Desktop, страница снова на месте.

## 4. Обновление

В Терминале:

```bash
cd ~/mk-forge && docker compose pull && docker compose up -d
```

Данные и книги остаются. Новая версия видна в шапке страницы.

## Если страница не открывается

1. Docker Desktop запущен? Если нет, запустить и подождать минуту.
2. Повторить в Терминале: `cd ~/mk-forge && docker compose up -d`.
3. Что пишет контейнер, видно в Docker Desktop: Containers → mk-forge → Logs.
